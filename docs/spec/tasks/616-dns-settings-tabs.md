## Проблема

Экран DNS объединяет серверы, стратегию, правила и настройки резолверов/кэша в одном длинном списке. Нужное действие требует прокрутки через не связанные друг с другом разделы.

## Решение

1. Разделить экран на три вкладки: «DNS Settings», «DNS Servers» и «DNS Rules».
2. По умолчанию открывать «DNS Settings». При переходе из журнала изменений открывать вкладку DNS-серверов или правил, если переданы `focusServerTag` или `focusRuleIdentity`.
3. На «DNS Settings» целиком перенести бывшую нижнюю часть экрана в прежнем порядке: DNS Final, Default Domain Resolver и предупреждение, размер кэша, Serve stale answers, Keep DNS cache after restart, Clear DNS cache. После неё разместить стратегию в компактном блоке с четырьмя вариантами выбора, без выпадающего меню.
4. Добавить на основную вкладку действия для добавления DNS-сервера и DNS-правила. На вкладках серверов и правил встроить кнопки «+» справа от названий вкладок, показывая значок только у активной вкладки. Удалить внутренние строки-заголовки с повторными кнопками; содержимое списков должно начинаться сразу под полоской вкладок.
5. Не менять модель данных, поведение DNS-правил, логику сохранения DNS или формат конфигурации.

## Риски и крайние случаи

- Переход по ссылке журнала должен открывать вкладку, содержащую целевую запись.
- Переключение вкладок не должно сбрасывать staged-изменения.
- Выбор стратегии должен сохранять прежнее поведение: пометка конфигурации как изменённой и запись в журнал изменений.
- Нажатие на «+» вызывает действие добавления, но не меняет активную вкладку; появление кнопки анимируется при свайпе.
