# §609 — Компактная строка автоперезапуска VPN в настройках

| Поле | Значение |
|------|----------|
| Статус | In progress — ожидает сборку и проверку на устройстве |
| Дата | 2026-10-11 |
| Область | App Settings → General → Behavior |
| Ветка | `experiment/final` |

## Проблема

Стандартный `SwitchListTile` занимает много ширины на иконку и переключатель,
из-за чего длинный заголовок и пояснение разбиваются на дополнительные строки.
Полное описание постоянно занимает место даже тогда, когда пользователю не
нужно читать подробности.

## Решение

- Добавить переиспользуемый `HintSettingTile` с иконкой слева, вертикальным
  переключателем справа, краткой подписью под заголовком и раскрываемым
  описанием за значком ⓘ.
- Временно применить компонент только к «Автоперезапуск VPN при смене настроек».
- Сохранить существующие обработчик и значение настройки; пока значения не
  загружены, строка остаётся неактивной.
- Сохранить локализацию короткой подписи для русского и китайского интерфейса.
- Свести дополнительный текст про настройку «При обновлении» в ту же
  раскрываемую подсказку.

## Критерии приёмки

1. Тап по строке или переключателю меняет только существующее значение настройки.
2. Тап по ⓘ открывает подробное описание; повторный тап закрывает его, не
   меняя настройку.
3. Левая и правая части строки занимают меньше места по краям, чем обычный
   `SwitchListTile`, оставляя больше ширины заголовку.
4. Остальные пункты настроек не меняются.
5. Строка отключена, пока настройки ещё загружаются.

## Проверка

Статический анализ и проверка переводов ещё не запускались через Actions.
После сборки необходимо проверить на устройстве перенос заголовка, раскрытие
описания и отсутствие переключения настройки при тапе на ⓘ.

## Не входит в задачу

Перевод остальных пунктов настроек на компактный формат и добавление отдельного
режима «Всегда показывать подсказки» в сохранённые настройки.
